## 范围

本项目收录**具有考古档案的复杂社会 / 早期文明**——不是现代民族国家，也不是维基上每一个文化名。

**纳入：** 有发掘遗址、已发表报告或耐久综合、且结构足以支撑可调用的 Source / Site / Period / Object / Claim 包。

**暂不纳入：** 无考古档案深度的纯民族志标签；现代国史；神话「失落大陆」；装饰性百科短条。

**诚信规则：** 目标不是维基式广度，而是**可调用、有出处**的包（含诚实的 `library-seed` 壳）。空着并标明，优于虚荣堆密度。

- **API：** `GET /api/v1/civilizations` 自动发现所有 `data/structured/*/civilization.json` — 第一波包为 `status: library-seed-rich`。
