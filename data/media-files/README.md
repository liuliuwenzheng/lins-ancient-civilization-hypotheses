# data/media-files

Openly licensed image files shown in `/ui` (decision D-2026-10-20-01). Repository code/data licensing does **not** apply to these files — each image keeps its **own** license (Public Domain, CC0, CC BY, or CC BY-SA), listed per file in `<pack>/ATTRIBUTION.md`.

- Files are web-sized copies (≤1600 px long edge, JPEG, <500 KB), resized only.
- CC BY-SA files are redistributed under the same license (ShareAlike).
- Not clearly open ⇒ not downloaded; such media stay outbound links only.
- The API serves this folder at `/media-files/…`; the UI prefers the local file and falls back to the upstream URL.

本目录图片各自保留原许可（公有领域 / CC0 / CC BY / CC BY-SA），逐图署名见各包 `ATTRIBUTION.md`；仓库本身的许可不覆盖这些图片。CC BY-SA 图片按相同方式共享再分发。
